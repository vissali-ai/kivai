# Kivai Capturador de Página Inteira

Extensão Manifest V3 para Chrome e Edge. Percorre a página ativa, captura os frames visíveis, une tudo em uma imagem PNG e oferece a caixa de diálogo de salvamento. O conteúdo da página permanece no navegador.

## Instalar

1. Extraia o ZIP.
2. Abra `chrome://extensions` no Chrome ou `edge://extensions` no Edge.
3. Ative o modo do desenvolvedor e selecione **Carregar sem compactação**.
4. Selecione a pasta extraída `kivai-fullpage`.

## Usar

Abra a página web, clique no ícone da extensão Kivai, escolha **Capturar página inteira** e aguarde a montagem do PNG.

O navegador precisa permitir captura da aba ativa. Páginas `chrome://`, a Chrome Web Store, páginas protegidas e documentos locais com acesso a arquivos desativado não podem ser capturados. A saída é limitada a 50 megapixels para evitar falta de memória.
